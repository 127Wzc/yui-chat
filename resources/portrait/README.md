# 人物画像内置提示词

来源：[Zhalslar/astrbot_plugin_portrayal](https://github.com/Zhalslar/astrbot_plugin_portrayal) 的 `builtin_prompts.yaml`。

采用版本：[`c45622b95ceb1b7f3d2a6b041a371c940b507981`](https://github.com/Zhalslar/astrbot_plugin_portrayal/tree/c45622b95ceb1b7f3d2a6b041a371c940b507981)。提示词文件按上游原文保留，许可证见同目录 [LICENSE](LICENSE)，版权属于 Zhalslar。

Yui Chat 将其中的画像、正画像、负画像、找对象和克隆人格作为独立任务，保留统一的资料权限、隐私与 JSON 传输规则；克隆人格正文放入可复制文本字段，不自动切换机器人身份。
